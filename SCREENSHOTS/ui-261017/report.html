HUD rebuild: before and after

PoKingHill · build 261017 · IMGUI HUD replaced by UI Toolkit (HudView + UI/Hud.uss) · captured in the editor's Game view at 1080×1920 unless noted.

What changed, in one list

  • One 9:16 column that never scrolls, with fixed corners: title top left, FPS top centre, menu top right, debug bottom left, build version YYMMDD bottom right (from the last commit date).
  • Menu becomes a bottom sheet with three tabs (Play · Agents · Settings); Quick match is one tap; every optional setting moved to Settings with plain defaults.
  • Results become a sheet that merges the winner, per-fighter telemetry (out time, distance, top speed, Elo change) and a Replay knock-out button.
  • Live strip: team-coloured score badges matching the robots' paint, sea clock, win-odds bar, hazard chip, commentary captions.
  • Touch works: the old IMGUI menu ignored touches (it needed the Game view). Safe-area padding follows Screen.safeArea.

Menu

Annotations

  1. Quick match: the champion against itself on Mountain top, one tap.
  2. Custom · N agents uses the Agents tab ticks; Tournament runs semi-finals and a final.
  3. You play: the player steers the walker brain with an on-screen stick or WASD.
  4. Corners stay visible above the sheet: debug (bottom left), version 261017 (bottom right).

In the round

Annotations

  1. Badges carry each fighter's colour, which is also its torso paint.
  2. Clock and sea bar: the bar fills as the water rises toward the summit.
  3. Win odds: the exported critic when one exists, otherwise a labelled physical estimate.
  4. Physics and brain timings moved to the debug panel (or the telemetry HUD setting).

Result

Annotations

  1. Headline and a stripe in the winner's colour; how it was won.
  2. Per fighter: result, out time, distance walked, top speed, Elo with the change from this round.
  3. Replay knock-out and Next round / Main menu with a countdown; in a tournament the bracket is listed.
